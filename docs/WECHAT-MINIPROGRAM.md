# 微信小程序版 · 接入与实测说明

> 一句话：把「给人数 + 人均预算 + 送到哪，算出麦当劳团餐最省的一单」做成微信小程序，
> 手机上点开就能用。**Token 不进小程序包**，算价仍然全部走麦当劳官方 `calculate-price`。

- 小程序源码：`miniprogram/`
- 云函数源码：`cloudfunctions/mcd/`（免域名、免备案那条路）
- 工程配置：仓库根目录 `project.config.json`（`miniprogramRoot` + `cloudfunctionRoot`）

---

## 1. 为什么必须有一层代理（这不是偷懒，是硬约束）

```
微信小程序 ──┐
            ├─ HTTP  ──▶ 你自己的服务（src/server.mjs）      ──┐
            └─ 云函数 ──▶ cloudfunctions/mcd（微信云开发）    ──┴──▶ mcp.mcd.cn
                                    ▲
                                    └── 唯一持有 MCP Token 的地方
```

两条硬原因：

1. **`mcp.mcd.cn` 不返回 CORS 头**（`Access-Control-Allow-Origin` 缺失），而且它是
   Streamable HTTP 的 JSON-RPC 服务端协议，HTTP 响应还可能是 `text/event-stream`。
   小程序/浏览器直接连会被同源策略与协议层同时拦掉。
2. **小程序包可以被反编译**。Token 是账号凭证（还能下单、能读你的地址簿），
   写进小程序等于公开。所以 Token 只能存在于「服务端进程内存」或「云函数环境变量」。

---

## 2. 三种玩法怎么选

| 玩法 | 需要什么 | 适合谁 | 代价 |
|---|---|---|---|
| **A. 开发者工具 / 真机预览** + 本机 HTTP 服务 | 电脑装 Node，跑 `node src/server.mjs` | 自己用、调参、开发 | 电脑要开着；手机与电脑同一 Wi-Fi |
| **B. 云开发云函数**（推荐日常用） | 小程序 AppID + 开通云开发（个人主体可开） | 脱离电脑、发给朋友体验 | 单次算价最长 60 秒；要开「快速模式」 |
| **C. 正式发布** | 已备案域名 + HTTPS 证书 + 服务器 | 上架给所有人用 | 备案耗时；`request` 合法域名要在后台配置 |

> 个人自己用，**B 是最省事的**：不需要域名、不需要备案、不需要公网服务器。

## 3. 快速开始 A：开发者工具 + 本机服务（5 步，零成本）

1. **起服务**（仓库根目录）：
   ```bash
   node src/server.mjs                 # 真实 Token（读 mcp-config.json）
   node src/server.mjs --demo          # 不想联网？演示数据先看界面
   ```
   窗口里会打印「电脑上打开 / 手机上打开」两个地址，以及一串 **6 位访问码**。

2. **导入小程序**：微信开发者工具 → 导入项目 → 目录选**仓库根目录**（不是 `miniprogram/`）
   → AppID 填你自己的；没有就先选「测试号 / 游客模式」。

3. **确认域名校验已关闭**：详情 → 本地设置 → 勾选
   **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。
   （`project.config.json` 里已默认 `setting.urlCheck: false`。）

4. **填设置**：小程序里进「设置」页 →
   - 通道选 **HTTP 服务**
   - 服务器地址：开发者工具里填 `http://127.0.0.1:8787`；
     **真机预览**填电脑的局域网 IP，例如 `http://192.168.1.23:8787`（同一 Wi-Fi）
   - 访问码：粘上第 1 步那 6 位（`--no-key` 启动可留空）
   - 点「测试连接」，看到「HTTP 服务 连接正常」即可

5. **回首页**：选「团餐比价」或「手机点餐」→ 填参数 → 开始算。

## 4. 快速开始 B：云开发云函数（免域名免备案）

1. 微信开发者工具里 **开通云开发**（选按量付费的基础版即可），记下 **环境 ID**（形如 `mcd-1a2b3c4d`）。
2. 右键 `cloudfunctions/mcd` → **上传并部署（云端安装依赖）**。
   该函数零依赖，但微信要求走「云端安装依赖」这一步。
3. **配置环境变量**：云开发控制台 → 云函数 → `mcd` → 配置 → 环境变量：

   | 变量 | 必填 | 说明 |
   |---|---|---|
   | `MCD_MCP_TOKEN` | 真实模式必填 | 你的 MCP Token（**不要**带 `Bearer ` 前缀） |
   | `MCD_MCP_URL` | 否 | 默认 `https://mcp.mcd.cn` |
   | `MP_ACCESS_KEY` | 否 | 设置后小程序必须带同样的「调用口令」，防止别人白用你的 Token |
   | `MP_DEMO` | 否 | 设为 `0` 关闭演示数据模式 |

4. **把超时改成 60 秒**：云开发控制台 → 云函数 → `mcd` → 配置 → 超时时间。
   **默认是 3 秒，不改必然超时**（团餐一次要跑几十次官方算价）。
5. 运行时**选 Node.js 16 或以上**（引擎用了 `??` / `?.`）。
   没有全局 `fetch` 的 Node 16 也能跑：`src/http-fetch.mjs` 提供了零依赖兜底。
6. 小程序「设置」页 → 通道选 **云函数** → 填环境 ID、函数名（默认 `mcd`）、
   调用口令（如果设了 `MP_ACCESS_KEY`）→ 测试连接。

> 云函数是「一次请求算到底」的同步模型，没有中间进度；界面会停在结果页并显示已用时。
> 建议首页打开 **快速模式**（默认已开）：团餐 45 次以内算价、手机点餐 36 次以内，实测 3~10 秒。

## 5. 正式发布需要什么（C）

| 要求 | 说明 |
|---|---|
| 小程序 AppID | 个人主体可注册；不能用测试号发布 |
| 服务器 | 公网可达，跑 `node src/server.mjs`（建议反代 + HTTPS） |
| 域名 | **已备案**，且在小程序后台「开发 → 开发设置 → 服务器域名」里把域名加入 **request 合法域名** |
| HTTPS | 微信正式版只允许 https（TLS 1.2+），不支持 IP、不支持自签证书 |
| 隐私协议 | 小程序后台填写隐私保护指引（会读取账号地址簿、调用支付链接复制） |

合规提醒：本项目只**算钱**，不代下单、不代支付；`create-order` 只在用户二次确认后
生成「未支付订单」，付款由用户本人在麦当劳完成。

## 6. 页面上有什么

| 页面 | 内容 |
|---|---|
| `pages/index` | 两种模式：**团餐比价**（人数 / 人均预算 / 收货地址 / 偏好）与 **手机点餐**（到店自取或麦乐送 / 城市 + 位置 / 想吃什么 / 预算）。可切「快速模式」和「演示数据」。 |
| `pages/result` | 实时日志 → 结果：🍟 最省的一单、跨门店比价、拆单结论、省在哪、凑单提示；手机点餐还有「这样点」清单、用券、操作步骤、券专属商品、已排除门店。可复制文字版文案；**真实 HTTP 模式**下可生成支付链接。 |
| `pages/settings` | 通道切换（HTTP / 云函数）、服务器地址、访问码、云开发环境 / 函数名 / 口令、连通性检测、恢复默认。 |

设计上刻意**不做登录**：地址簿来自你自己的麦当劳账号（Token 决定）。

## 7. 数据契约（想接自己前端的话）

HTTP 服务（`src/server.mjs`）新增了一个**增量轮询**参数，专为没有 SSE 的客户端准备：

```http
POST /api/jobs                          # 建任务，立刻返回 { ok, jobId, kind }
GET  /api/jobs/{jobId}?from=N           # 只回第 N 条之后的新日志
```

`?from=N` 的返回：

```json
{ "ok": true, "job": {
  "id": "...", "kind": "optimize", "status": "running|done|failed",
  "logs": ["仅新增的日志"], "logTotal": 12,
  "startedAt": 0, "endedAt": null,
  "result": "仅在 status !== running 时出现",
  "error": "仅在 failed 时出现"
}}
```

不带 `from` 时行为与以前完全一致（返回全量 `job`），所以网页版 SSE 客户端不受影响。

云函数的入参/出参：

```js
// 入
{ kind: 'optimize' | 'phone' | 'ping', params: {...}, demo: true|false, key: '调用口令' }
// 出
{ ok: true, kind, demo, result, text, callsUsed, canOrder: false, logs, elapsedMs }
{ ok: false, error: { message, code } }
```

`result` 经过 `src/slim.mjs` 裁剪（去掉 `storeReports`、每个方案的原始 `price` 回执），
团餐结果从几百 KB 压到 **10 KB 量级**——因为云函数返回值有 1MB 级上限，
而界面一个字段都用不到那些原始回执。文字版 `text` 在裁剪**之前**生成。

## 8. 真实实测（2026-10-18，真 Token，走的就是小程序的 api.js）

| 场景 | 结果 |
|---|---|
| HTTP 通道 · 手机点餐（西安市 长安大厦，巨无霸 + 中杯美式） | 3 家门店比价，**¥38.80**，用券「新人专享-中杯美式7折」，券省 ¥5.70，**3.9 秒** |
| HTTP 通道 · 团餐（20 人 / 人均 ¥35 / 长安大厦） | 6 个方案，最优 **¥512.20（人均 ¥25.61）**，优惠 −¥211.80（31.1%），拆单结论「别拆」，**7.8 秒** |
| 云函数通道 · 手机点餐（强制删掉全局 fetch，模拟 Node 16） | 2 家门店，**¥38.80**，6 次算价，**2.7 秒**，返回值 **6 KB** |
| 云函数通道 · ping | `mcd-mcp 1.0.0` 握手成功 |

## 9. 实测踩到的坑（都是真跑出来的，不是推演）

1. **`enjoyable.realDiscount` 的单位是「折」，不是 0~1 的小数。**
   实测值是 `7.8`（7.8 折）、`balance: 27000`（分）。按 `0.7` 处理会打印出
   **「70 折」**这种错话——第一次真实链路跑通时就看见了，已修正并加了单测。
2. **小程序没有 `EventSource`**，SSE 用不了。所以 HTTP 通道改成了
   「建任务 + `?from=N` 增量轮询」；不是简单把 SSE 搬过来。
3. **每 900ms 重传全量结果会拖死手机网络。** 真实团餐结果几百 KB，所以
   `running` 阶段服务端**绝不返回** `result`，且只回新增日志（每次几百字节）。
4. **云函数返回有 1MB 级上限。** 不裁剪的话，团餐结果带 `storeReports` 很容易撞线；
   现有 `src/slim.mjs` 裁到 10 KB 量级，并有单测断言「裁剪后变小且渲染结论一致」。
5. **云函数默认超时 3 秒。** 不改配置必然失败，且报错很难懂；现在错误映射里
   直接给出「去控制台把超时改成 60 秒 / 打开快速模式」。
6. **真机预览与体验版/正式版的域名策略不同。** 开发者工具与「预览」可以靠
   「不校验合法域名」连局域网 HTTP；**体验版/正式版必须 HTTPS + 已备案域名白名单**。
   这一点在文档里单独标出，避免有人以为「预览能跑就代表能发布」。
7. **云函数没有跨请求的 MCP 会话**，所以云函数模式下 `canOrder: false`，
   不提供「生成支付链接」按钮；下单只在 HTTP 模式可用（服务端复用同一个 MCP 会话）。
8. **打烊门店会返回 `600057` + 空菜单**，不能当成「这家店没有团餐」。
   小程序沿用了引擎的 `closed` 语义，结果页会明确列出「已排除（非营业时间）」。
9. **地址只能来自 `addressId`。** 小程序不硬编码地址，而是先 `GET /api/addresses`
   拉地址簿给用户选；云函数模式则由引擎在云函数内匹配地址关键词。

## 10. 常见报错对照表

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| `连不上服务（request:fail ...）` | 地址错 / 服务没起 / 不同 Wi-Fi / 域名校验没关 | 按提示四条逐一排；真机用局域网 IP |
| `访问码不正确` | 访问码过期（每次启动都变）或填错 | 看电脑窗口里的 6 位，重新填 |
| `账号地址簿是空的` | 账号里没有收货地址 | 麦当劳 App → 我的 → 收货地址 保存一个 |
| `地址在账号地址簿里匹配不上` | 关键词和地址对不上 | 换地址里的地标词，例如「长安大厦」 |
| `云函数没有配置 MCP Token` | 没加 `MCD_MCP_TOKEN` 环境变量 | 云开发控制台加变量后重新部署 |
| `云函数调用失败（timeout）` | 云函数 3 秒超时 / 算价太多 | 超时调 60 秒；打开快速模式 |
| `没有找到这个云函数` | 没部署 / 函数名不对 | 右键 `cloudfunctions/mcd` 上传并部署；核对设置里的函数名 |
| `门店都打烊了` | 到店自取的门店当前不在营业时间 | 换时间，或改用麦乐送（外送营业时间更长） |
| `本次共调用官方算价 N 次` 后无方案 | 调用预算用尽或门店无菜单 | 打开快速模式重试，或换门店/时间 |

## 11. 安全说明

- 仓库、小程序包、云函数源码里**没有任何真实 Token**；`mcp-config.json` 被 `.gitignore` 排除。
  单测 `test/miniprogram.test.mjs` 会扫一遍仓库关键目录，若出现真实 Token 直接失败。
- 云函数的 Token 放**环境变量**；可选 `MP_ACCESS_KEY` 再做一道调用口令。
- HTTP 服务的 Token 只存在于进程内存；接口响应里不含 Token；默认 6 位访问码鉴权。
- 小程序包可被反编译，所以**永远不要**把 Token 塞进 `wx.request` 的 header 或本地存储。

## 12. 测试

```bash
node test/miniprogram.test.mjs     # 23 项：工程完整性 / 视图模型 / api.js 端到端 / 云函数 / fetch 兜底 / 泄露扫描
node tools/build-mp-cloud.mjs --check   # 云函数 lib 与 src/ 是否同步（单测里也会跑）
```

其中最有价值的两条：

- **api.js 端到端**：用假 `wx` 把小程序真实的 `utils/api.js` 打到真实的 `src/server.mjs`
  （demo 模式），走完「ping → 地址簿 → 建任务 → 增量轮询 → 结果 → 下单被拒」全链路，
  并断言 `running` 阶段绝不带 `result`、游标消费后必须是 0 条新日志。
- **云函数端到端**：直接把 `cloudfunctions/mcd/index.js` 当本地函数调用（含 demo 与错误码），
  并断言「裁剪后的结果仍能被视图层渲染」。
